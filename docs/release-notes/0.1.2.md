# CipherChat 0.1.2 (2026-10-25)

A maintenance release of CipherChat by DarkCipher Systems, a self-hosted chat with voice and video calls where every
message, file and call frame is end-to-end encrypted with post-quantum hybrid cryptography, on your own server.

It exists to give privacy and control of conversations back to the people having them: no company in the middle, no
one else's rules, no data to sell or hand over, and open code anyone can check.

## Changes since 0.1.1

* **Cleaner source release**: two cross-client test fixtures (random encrypted bytes) are regenerated, and the
  test suites no longer rewrite committed fixtures on every run. The release's privacy scan now matches private terms
  anywhere in every file, tests included. The apps, server and protocol work exactly as in 0.1.1.

## Everything in this release

* **Your own server** on Linux (nginx: its own site, merged into one of yours, or behind your proxy; Let's Encrypt;
  coturn call relay; nightly backups; `cipherchat-admin`), jailed with systemd. The server never holds a key that
  opens a message. Upgrades keep every setting and all data, refuse older releases, copy the database first and roll
  back by themselves if the new version doesn't start.
* **Deleted usernames can be used again**: inviting a name whose account was deleted creates a fresh account (new
  identity, certified again by the owner); before, the name stayed taken for good.
* **A phone layout for the web chat**: the chat fills the screen, the message box has its own full-width line (16 px,
  so iPhones don't zoom), and the buttons are sized for fingers.
* **Web chat** at `/chat/`, a **Windows app** and an **Android app**, with the same protocol and features everywhere.
* **Post-quantum end to end**: ML-KEM-1024 + X25519 key wrapping, ML-DSA-87 + Ed25519 signatures, AES-256-GCM, SHA-3,
  identities sealed with Argon2id. The apps only connect over TLS 1.3 with X25519MLKEM768.
* **Trust you can check**: one 60-digit safety number with the owner, owner-signed certificates for everyone else, and
  key changes refused loudly.
* **Private rooms and direct messages**: replies, reactions, edits, deletes, files and pictures up to 100 MB, burn
  after reading, per-room retention. A room is visible only to the people added to it.
* **Colour emoji, GIFs and text size**: emoji in full colour on every client (the Windows app draws Windows' own
  Fluent emoji through DirectWrite), big emoji-only messages, a larger picker; GIFs that play inline, a GIF button with
  the GIFs of your session, and keyboard GIFs on Android, all encrypted like any attachment and with no GIF search
  service involved; text size from 90% to 200% on every client.
* **Calls**: voice and 1080p video for up to 8 people, screen sharing (web and Windows), every frame end-to-end
  encrypted inside WebRTC, call words to check a call, push-to-talk, hand raise, reactions, Android picture-in-picture.
* **Made for bad networks**: an outbox on every client queues what you send while the connection is down and sends it,
  in order and exactly once, when it's back.
* **Server administration** on the admin page: server name, sign-up, password, session and lockout policy, attachment
  size; email (SMTP, with the password sealed on the server) and six notifications; **granular permissions** (16
  permissions, editable and custom roles, per-person grants and denies, and rules nobody can use to promote themselves).
* **No IP addresses kept**: CipherChat stores and logs no client addresses; its security records keep a tag that
  changes daily and can't be turned back into an address.
* **Add-ons**: programs with their own post-quantum identity and per-request HMAC-SHA3-256 signatures (no bearer
  tokens), and a .NET SDK for your own.
* **Sign-in** with password + authenticator, passkeys (Windows Hello, Android, Bitwarden and other providers) and
  device pairing codes.
* **Android**: keys in a hardware-backed vault behind fingerprint or screen lock, private notifications, incoming-call
  screen, auto-lock.
* A DarkCipher-themed Windows installer (Setup.exe, plus an MSI for administrators), a checksummed Linux server
  release and a signed Android APK.

A penetration test and debug sweep is in `docs/security/PENTEST-2026-10.md`: server functional (21), pentest (20),

`docs/security/SECURITY-DESIGN.md`.

## Known limits

* The Windows installers aren't Authenticode-signed yet: SmartScreen warns and Smart App Control blocks them. Check
  the SHA-256 against `SHA256SUMS`.
* Android passkeys need the server to list the app (`CIPHERCHAT_ANDROID_APPS`).
* Group calls are a mesh (up to 8 people).
* Mac and iOS are planned (`docs/MAC-IOS-HANDOFF.md`).
